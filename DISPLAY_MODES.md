# Display Settings

## Windowed
Godot mode Window.MODE_WINDOWED
"Обычное" окно с рамкой (рамки нет на нативном разрешении)
размер окна выбирается в интерфейсе
доступны все разрешения, поддерживаемые активным монитором и не превышающие его текущее разрешение
окно центрируется на активном мониторе
последнее выбранное разрешение сохраняется.

## Borderless
Godot mode Window.MODE_FULLSCREEN
полноэкранное окно без рамки
используется текущее разрешение и герцовка активного монитора, вызывается DisplayServer.screen_get_size()
изменение разрешения и частоты обновления недоступно

## Fullscreen
Godot mode: Window.MODE_EXCLUSIVE_FULLSCREEN
эксклюзивный полноэкранный режим
доступны разрешения и частоты обновления, поддерживаемые активным монитором
при выборе разрешения автоматически устанавливается максимальная доступная частота обновления
частоту обновления можно изменить вручную из списка поддерживаемых по winapi

## Resolution
список разрешений доступен в Windowed и Fullscreen
В Borderless отображается текущее разрешение монитора.
в Fullscreen разрешение выбирается отдельно от частоты обновления
в Windowed доступны разрешения, поддерживаемые активным монитором и не превышающие его текущее разрешение
при возврате в Windowed восстанавливается последнее выбранное разрешение.

## Refresh Rate
доступен только в Fullscreen
список частот обновления зависит от выбранного разрешения
по умолчанию выбирается максималная доступная частота

## Render Scale
Не реализован
base Viewport 1920×1080
Stretch Mode canvas_items 
Stretch Aspect expand

## Settings Persistence
текущие параметры сохраняются в %APPDATA%\Godot\app_userdata\Hindsight в файл settings.cfg и подгружаются при следующем запуске игры
сохраняются режим отображения, оконное разрешение и полноэкранное разрешение с частотой обновления
значение по умолчанию BORDERLESS
если сохранённое оконное разрешение недоступно на активном мониторе, выбирается 1920 × 1080, если оно доступно. иначе выбирается наибольшее доступное разрешение.




ВСЕ изменения в герцовке и разрешении применяются временно с подтверждением в течение 15 секунд
при отсутствии подтверждения автоматически восстанавливаются предыдущие настройки

TLDR
Windowed — меняется размер игрового окна. Разрешение рабочего стола Windows не затрагивается.
Borderless — окно разворачивается на весь экран монитора. Используется текущее разрешение рабочего стола.
Fullscreen — меняется разрешение самого монитора через Windows API, затем игра переключается в MODE_EXCLUSIVE_FULLSCREEN.
